## 1. Critical recurrent-parameter diagnostic (`delta_theta -> D_theta J_t[delta_theta]`)

Computed the full `(r,r,r)` tensor `d(J_t[p,q])/d(theta_i)` via nested
`jax.jacobian` (independent of the theory-predicted closed form),
extracted the algebra element generated by each basis direction `e_i`
(its column-0 slice), and — before trusting this shortcut — explicitly
verified each directional-derivative slice really IS a
regular-representation matrix `M_{delta_u_i}` (not merely assumed):
max discrepancy ~1e-17 to 5.5e-17 at every one of 8 sampled points.

**8/8 checks: rank 64/64, well-conditioned (unlike the S_t rank check
in B34a, which becomes ill-conditioned only over long accumulation

stays well-scaled).**

**Precise condition used** (derived analytically and confirmed
numerically): `D` equals `M_{Z_t}` exactly for a fixed algebra element
`Z_t = 6c3·y_t·(kappa_t*h_t+b_t)*A_theta_t + d_t*kappa_t`, so
`rank(D)=r` iff `Z_t[0]≠0`. Since `d_t[0]=c1+3c3·y_t[0]²≥c1=1.0`
**structurally** (a positive constant plus a nonnegative term) and
`kappa_t[0]` is forced into `[0.2,0.8]` (a unit), the term
`d_t[0]·kappa_t[0]≥0.2` is a **guaranteed** lower bound on part of
`Z_t[0]` — it can only vanish via an exact, non-generic cancellation
with the other (freely varying) term. This is the reason B34 is
strictly stronger than B33b-min: there, theta entered only additively;
here, `D_theta J_t` genuinely has rank r, confirming all r independent
theta components change the recurrent transformation itself.
